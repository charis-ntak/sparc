    Attribution and the direct estimator¶

    The pool of feature level attributions¶

    sparc.attribution ¶

    Feature level Shapley attribution over bootstrap resamples and model classes.

    This module implements Steps 1 and 2 of the SPARC algorithm. The reference model is fitted on the training data, the training data is resampled B times, every model class is refitted on every resample, and feature level Shapley values are computed for the instances to be explained with a background sample drawn from the resample. Resample index 0 is always the original training data, so that with B = 1 and M = 1 the pool reduces to the Shapley values of the reference model, which is required for the exact reduction to SHAP.

    shapley_values ¶

    shapley_values(model, X_explain, background, task, explainer='auto', target_class=1, kernel_nsamples='auto', permutation_max_evals='auto', seed=0)

    Compute feature level Shapley values for X_explain.

    Returns the matrix of Shapley values with shape (n_explain, n_features) and the expected value of the explained output over the background sample. All estimators use the interventional (marginal) expectation with respect to the whole background sample, which is handed to shap as an explicit masker so that no subsampling takes place, and the efficiency property holds with respect to the mean background output. The kernel estimator runs without the l1 feature preselection of shap, so that it targets the full Shapley vector, and it is seeded from seed through the global numpy state, which is restored afterwards, because shap's KernelExplainer draws its coalitions from that state.

    aggregate_to_concepts ¶

    aggregate_to_concepts(values, U)

    Equation 1: concept level attribution from feature level attribution.

    phi_k = sum_j u_jk phi_j, applied along the last axis of values. Works for pools of shape (..., n_features) and returns (..., n_concepts).

    redistribute_to_features ¶

    redistribute_to_features(concept_values, U, feature_weights=None)

    Defuzzified feature level vector from concept centroids.

    Each concept value is redistributed to the features in proportion to their membership in the concept: psi_j = sum_k c_k u_jk / sum_j' u_j'k. With feature_weights (one non negative weight per feature, for example the mean absolute feature level attribution of the pool) the share of feature j in concept k is u_jk w_j / sum_j' u_j'k w_j', so that the concept total is unchanged but the credit follows the importance of the members. With an identity membership matrix this returns the concept values unchanged, so the operation reduces to ordinary SHAP for singleton crisp concepts.

    default_model_classes ¶

    default_model_classes(task, random_state=0)

    Return the default set of model classes used to quantify model dependence.

    The first entry is the reference model class. Gradient boosting, random forest and a multilayer perceptron are used, as suggested in the study design guide.

    Shapley values over fuzzy concepts¶

    sparc.concept_shapley ¶

    Shapley values computed directly over fuzzy concepts (the direct concept estimator).

    The aggregated estimator of Equation 1 forms a concept attribution as the membership weighted sum of feature level Shapley values. The direct estimator of this module treats every fuzzy concept as a player of a cooperative game. A coalition S of concepts keeps feature j to the degree

    w_j(S) = min(1, sum_{k in S} u_jk),

    the membership mass of j in S, so that the grand coalition keeps every feature entirely whenever the rows of the membership matrix sum to one, and the empty coalition removes every feature. The value of a coalition is the model output of the explained instance with the remaining features removed to the degree 1 - w_j(S), by conditional imputation (mean of the nearest background rows on the kept features, the operation that the deletion and insertion curves of the deletion and insertion tests of the study perform) or by marginal imputation (mean output over the background sample, the interventional expectation of grouped Shapley values). The Shapley value of concept k is the usual weighted average of its marginal contributions; with at most max_exact_concepts concepts every coalition is enumerated, otherwise antithetic permutation sampling is used.

    Properties (checked in tests/test_concept_shapley.py):

    • efficiency: the concept values sum to the output of the explained instance minus the value of the empty coalition, for every membership matrix whose rows sum to one;
    • reduction: with the identity membership matrix and marginal imputation the values equal the interventional feature level Shapley values, and with a crisp partition they equal the grouped Shapley values of the baseline;
    • symmetry and duplication invariance follow from the game being defined on the membership mass of a coalition, so that an exact copy of a feature that joins its concept changes no coalition value.

    fuzzy_removal_weights ¶

    coalition is a boolean mask of length K. Returns a vector of length d with entries 1 - min(1, sum of the memberships of the present concepts).

    Synthetic problems¶

    sparc.synthetic ¶

    Synthetic data generating processes with known concept structure (Phase A).

    Three families are implemented. In the additive family the response is a sum of functions of latent factors, each factor being measured by a block of correlated observed features. In the interaction family a product term between the first two factors is added. In the redundancy family exact and near duplicates of features are appended, which produces the credit splitting failure of feature level attribution.

    Every latent factor z_k is standard normal and every observed feature of block k is x_j = sqrt(rho) z_k + sqrt(1 - rho) e_j, so that the within block correlation equals rho and every feature is standard normal. Given the block, the factor is normal with mean c_k * sum_j x_j and variance tau_k^2, which gives the true regression function and the true concept attributions in closed form (Gauss Hermite quadrature is used for nonlinear links).

    SyntheticProblem dataclass ¶

    A synthetic problem with known ground truth.

    true_concept_attributions ¶

    true_concept_attributions(X)

    True attribution of every factor for every row of X, shape (n, n_factors).

    Because the regression function is additive across independent blocks, the Shapley value of block k with the marginal baseline is the centered block contribution. For the interaction term gamma z_1 z_2 the Shapley value splits the centered product equally between the two factors.
