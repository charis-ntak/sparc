    Explainer and Explanation¶

    sparc.explainer.Explainer ¶

    Bases: BaseEstimator

    Pareto optimal fuzzy concept attribution.

    Parameters:

    Name Type Description Default
    model_classes list of estimators or (name, estimator) pairs

    Model classes used to quantify model dependence. The first is the reference model class. None uses gradient boosting, random forest and a multilayer perceptron.

    		 None
    n_resamples int

    Number of bootstrap resamples B (resample 0 is the original data).

    		 50
    background_size int or None

    Background sample size for the Shapley computation.

    		 100
    explainer ('auto', 'tree', 'linear', 'kernel', 'exact', 'permutation')
    		'auto'
    n_concepts_grid iterable of int

    Candidate numbers of concepts K. A value equal to the number of features d gives the identity partition (one crisp concept per feature, the K = d case of the reduction to feature level Shapley values), which is also the fallback when no other data driven candidate can be formed; values outside 1 to d are ignored with a warning.

    		 (2, 3, 4, 5, 6)
    fuzzifier_grid iterable of float
    		(1.5, 2.0, 2.5)
    concept_distance ('correlation', 'loading')
    		'correlation'
    correlation ('pearson', 'spearman')
    		'pearson'
    apriori_groups dict or list

    Known grouping of the features, included as a candidate partition.

    		 None
    partition_source ('data', 'apriori', 'both')

    Which candidate partitions enter the selection.

    		 'data'
    consensus bool

    Consensus fuzzy c means over resamples of the instances.

    		 False
    crisp_concepts bool

    Ablation: harden the concept partitions.

    		 False
    fuzzy_shape ('trapezoidal', 'triangular')
    		'trapezoidal'
    support_percentiles pairs of floats
    		(5.0, 95.0)
    core_percentiles pairs of floats
    		(5.0, 95.0)
    disagreement_threshold float

    Disagreement index above which an attribution is upgraded to type 2.

    		 0.5
    linguistic_labels LinguisticLabelSet
    		None
    linguistic_scale ('mean_abs', 'output_sd')
    		'mean_abs'
    alpha_grid iterable of float
    		(0.0, 0.25, 0.5, 0.75, 1.0)
    sparsity_grid iterable of int or None
    		None
    solver ('grid', 'nsga2', 'fixed')

    'fixed' evaluates only fixed_configuration (ablation).

    		 'grid'
    fixed_configuration dict

    Keys n_concepts, fuzzifier, sparsity, alpha (or partition='apriori').

    		 None
    knee_method ('utopia', 'hyperplane')
    		'utopia'
    surrogate ('linear', 'tree')
    		'linear'
    concept_estimator ('aggregate', 'direct')

    How the concept attributions of the selected partition are estimated. 'aggregate' forms them from the feature level Shapley values of the pool (Equation 1), which is also what the Pareto selection uses for every candidate partition. 'direct' recomputes the pool of the selected partition with Shapley values over the fuzzy concepts themselves (:mod:sparc.concept_shapley), whose coalitions remove features to the degree of their membership exactly as the deletion and insertion tests do.

    		 'aggregate'
    direct_imputation ('conditional', 'marginal')

    Imputation of the removed features in the direct estimator.

    		 'conditional'
    point_estimate ('reference', 'centroid')

    Point attribution reported beside the fuzzy number: the attribution of the reference model on the original data (default; the fuzzy number, the sign confidence and the disagreement still describe the whole pool), or the centroid of the trapezoid over the pool.

    		 'reference'
    feature_weights ('membership', 'importance')

    How a concept's credit is redistributed to its features by :meth:Explanation.feature_attribution.

    		 'membership'
    task ('auto', 'regression', 'classification')

    See :class:sparc.attribution.AttributionEngine.

    		 'auto'
    target_class int or label

    Class whose probability is explained for classifiers, given as one of the class labels or as an index into the sorted classes; the resolved class is exposed as classes_ and target_class_ after fitting.

    		 1
    n_jobs int
    		1
    random_state int or None
    		None

    fit ¶

    fit(X, y, feature_names=None)

    Fit the pool of models and form the candidate concept partitions.

    from_engine classmethod ¶

    from_engine(engine, feature_names=None, **kwargs)

    Build an explainer around an already fitted attribution engine (shares the pool of models).

    The engine level parameters (model_classes, n_resamples, background_size, explainer, task, target_class, kernel_nsamples, permutation_max_evals, n_jobs, random_state and verbose) are copied from the engine so that get_params describes the pool that was fitted. Any constructor argument, including these, may be given as a keyword argument and then takes precedence; a random_state override affects the concept formation and the Pareto selection only, since the pool is not refitted.

    sparc.explainer.Explanation dataclass ¶

    Outputs of SPARC for a set of explained instances (Section 3.6 of the guide).

    values property ¶

    values

    Point concept attribution, shape (n_explain, K).

    base_values property ¶

    base_values

    Value the concept attributions are measured from, shape (n_explain,).

    For the aggregated estimator it is the expected output of the reference model over its background sample; for the direct estimator it is the value of the empty coalition of the reference model. With point_estimate='reference' values.sum(axis=1) + base_values equals the reference model output of every instance.

    output property ¶

    output

    Output of the reference model for every explained instance.

    names property ¶

    names

    Concept names.

    X property ¶

    X

    The explained instances (feature level), when the explanation carries them.

    data property ¶

    data

    Concept scores of the explained instances, shape (n_explain, K).

    The membership weighted mean of the standardized features of every concept (standardized with the training mean and standard deviation), used to colour the beeswarm and the dependence plots.

    importance property ¶

    importance

    Mean absolute point attribution of every concept over the explained instances.

    concept_centroids property ¶

    concept_centroids

    Point concept attribution, shape (n_explain, K).

    The centroid of the trapezoidal fuzzy number by default; with point_estimate='reference' the attribution of the reference model on the original data (pool member b = 0, m = 0), the fuzzy number and the sign confidence still describing the whole pool.

    front property ¶

    front

    The Pareto optimal configurations with their objectives and flags (the front as a table).

    configurations property ¶

    configurations

    Every evaluated configuration with its objectives, pareto and knee flags.

    fidelity_optimal property ¶

    fidelity_optimal

    Index of the front member with the smallest fidelity loss (ties broken by complexity, then instability).

    __getitem__ ¶

    __getitem__(item)

    Explanation of a subset of the explained instances: e[i], e[2:5] or e[[0, 3]].

    Every per instance quantity is sliced; the partition, the selection and the global quantities are shared. Integer indexing keeps one instance (len(e[i]) == 1) so that the per instance plots and describe(0) apply to the result.

    feature_attribution ¶

    feature_attribution(retained_only=False)

    Defuzzified feature level vector obtained by redistributing concept centroids.

    With feature_weights='importance' the share of a feature in its concept follows its mean absolute feature level attribution over the pool instead of its membership alone (the concept totals are unchanged).

    fuzzy_attribution ¶

    fuzzy_attribution(instance, concept)

    Fuzzy attribution of one instance and concept; type 2 when the model classes disagree.

    best_labels ¶

    best_labels()

    Most compatible label index and degree for every instance and concept.

    Ties at the maximal compatibility are broken by the tie breaking rule of :meth:LinguisticLabelSet.best_label (the label whose center is closest to the centroid of the standardized attribution).

    at ¶

    at(index)

    The explanation of another evaluated configuration, for example another member of the front.

    The pools of the candidate partitions are reused, so the call is cheap; for the direct estimator only the partition of the selected configuration carries direct concept values, the other partitions keep the aggregated ones. Instance subsets are preserved.
