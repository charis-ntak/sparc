    Concepts and fuzzification¶

    Concepts¶

    sparc.concepts ¶

    Fuzzy concept formation from correlated features.

    Concepts are formed by fuzzy c means clustering applied to the features rather than to the instances. Every feature is represented by its profile of absolute correlations with all features, so that two features with similar correlation patterns are close, or by a varimax rotated factor analytic loading matrix normalized row wise when a latent structure is assumed. An a priori grouping, for example the subscales of a questionnaire, can be included as an additional candidate partition.

    ConceptPartition dataclass ¶

    A fuzzy partition of the features into concepts.

    Attributes:

    Name Type Description
    U ndarray of shape (n_features, n_concepts)

    Membership matrix with rows summing to one.
    name str

    Identifier used in the configuration tables.
    method str

    How the partition was obtained ('fcm', 'loading', 'apriori', 'identity').
    fuzzifier float or None
    feature_names list of str

    Any sequence of names (list, tuple, pandas Index or array) is accepted and stored as a list. It must hold one name per feature; when empty or None the names default to x0, x1, and so on.

    fit ¶

    fit(X, feature_names=None)

    Form the candidate partitions of the columns of X.

    No value of K satisfies 1 <= K < d when d equals one, so a single feature yields the identity partition as its only candidate.

    partition ¶

    partition(n_concepts, fuzzifier)

    Return (and cache) the candidate partition with K concepts and the given fuzzifier.

    fuzzy_c_means ¶

    fuzzy_c_means(Z, n_clusters, fuzzifier=2.0, max_iter=300, tol=1e-07, n_init=5, random_state=None)

    Fuzzy c means clustering of the rows of Z.

    Returns the membership matrix U of shape (n_rows, n_clusters) whose rows sum to one, the cluster centers and the final objective value. Several random initializations are run and the solution with the smallest objective is kept. Clusters are ordered by the index of their first dominant row so that the output is deterministic for a given seed. The membership update is written in terms of the ratio of every squared distance to the smallest squared distance in its row, which is the same update algebraically but stays finite for fuzzifier values close to one.

    consensus_membership ¶

    consensus_membership(X, n_clusters, fuzzifier=2.0, n_resamples=20, correlation='pearson', random_state=None, n_init=3)

    Consensus fuzzy c means over bootstrap resamples of the instances.

    The co-membership matrix (probability that two features share the dominant concept) is averaged over resamples, and fuzzy c means is run once more on the rows of the consensus matrix. This mitigates the instability of the partition on small samples.

    loading_membership ¶

    loading_membership(X, n_factors, random_state=None)

    Membership matrix from absolute varimax rotated factor loadings normalized row wise.

    A maximum likelihood factor solution is determined only up to an orthogonal rotation, so the unrotated loadings are not identified and a membership matrix derived from them would depend on an arbitrary representative. The loadings are therefore varimax rotated, which selects the representative with the simplest structure and makes the membership matrix well defined.

    apriori_membership ¶

    apriori_membership(groups, n_features, feature_names=None)

    Crisp membership matrix from an a priori grouping of features.

    Features that appear in no group are collected in one additional concept.

    identity_partition ¶

    identity_partition(n_features, feature_names=None)

    One crisp concept per feature; SPARC reduces to SHAP on this partition.

    correlation_profile_embedding ¶

    correlation_profile_embedding(X, method='pearson')

    Embed every feature as its vector of absolute correlations with all features.

    Fuzzification¶

    sparc.fuzzification ¶

    Fuzzification of attribution distributions.

    The concept attributions obtained across resamples and model classes form an empirical distribution which is summarized by a trapezoidal fuzzy number whose support is given by the 5th and 95th percentiles and whose core by the 25th and 75th percentiles (Equation 2). Sign confidence, the disagreement index between model classes, interval type 2 upgrades, linguistic labels through the fuzzy compatibility measure (Equation 3), and the possibility degree used for fuzzy ranking are implemented here.

    TrapezoidalFuzzyNumber dataclass ¶

    Trapezoidal fuzzy number with support [a, d] and core [b, c].

    centroid ¶

    centroid()

    Centroid of the trapezoid, always inside the support [a, d].

    The closed form is evaluated after translating the trapezoid to its left endpoint a, which avoids the catastrophic cancellation of the raw formula when the four parameters are nearly equal but far from zero, as happens when pool members coincide up to floating point noise. A degenerate (crisp) number returns its single value.

    IntervalType2FuzzyNumber ¶

    Interval type 2 fuzzy number whose footprint of uncertainty is the union of type 1 numbers.

    The upper membership is the pointwise maximum and the lower membership the pointwise minimum of the member fuzzy numbers, one per model class.

    footprint ¶

    footprint()

    Trapezoidal envelope of the footprint (outer support, outer core).

    compatibility ¶

    compatibility(A)

    Compatibility interval (lower, upper) with a linguistic set A.

    LinguisticLabelSet ¶

    Fixed fuzzy sets over the standardized attribution axis.

    The default is a Ruspini partition with five labels: strongly negative, weakly negative, negligible, weakly positive and strongly positive, whose cores are centered at -2, -1, 0, 1 and 2 units of the standardization scale. Alternative label sets can be supplied for the sensitivity analysis.

    centers property ¶

    centers

    Representative point of every label on the standardized axis, used to break ties between labels.

    with_breakpoints classmethod ¶

    with_breakpoints(centers, names=None)

    Ruspini partition with triangular labels at the given centers and shoulders at the ends.

    profile ¶

    profile(F, scale=1.0)

    Equation 3 evaluated for every label on the standardized axis.

    best_label ¶

    best_label(F, scale=1.0)

    Label with the largest compatibility (Equation 3) and its degree.

    Equation 3 is a possibilistic measure, so every label whose core meets the core of F has compatibility one and a wide attribution ties for two or more labels. Ties are broken by the distance between the centroid of the scaled attribution and the representative point of the label (centers); a remaining tie goes to the first label in order.

    best_label_array ¶

    best_label_array(Q, scale=1.0, profile=None)

    Index and degree of the best label for every quantile vector in Q (..., 5).

    The tie breaking rule of best_label is applied to the whole array. profile may pass the output of profile_array for the same Q and scale so that the compatibilities are not recomputed. Returns two arrays of shape Q.shape[:-1].

    profile_array ¶

    profile_array(Q, scale=1.0)

    Compatibility of every quantile vector in Q (..., 5) with every label: shape (..., n_labels).

    fuzzify ¶

    fuzzify(samples, shape='trapezoidal', support_percentiles=(5.0, 95.0), core_percentiles=(25.0, 75.0))

    Equation 2: trapezoidal (or triangular) fuzzy number from an empirical sample.

    fuzzify_array ¶

    fuzzify_array(samples, axis=0, shape='trapezoidal', support_percentiles=(5.0, 95.0), core_percentiles=(25.0, 75.0))

    Vectorized Equation 2.

    Returns an array whose last axis holds the five quantiles (support low, core low, median, core high, support high). For the triangular shape the core values equal the median.

    sign_confidence ¶

    sign_confidence(samples, axis=0)

    Proportion of pool members whose attribution has the sign of the median.

    disagreement_index ¶

    disagreement_index(values)

    Ratio of the between model class variance to the total variance.

    values has shape (B, M, ...) with resamples on axis 0 and model classes on axis 1. Returns an array of shape values.shape[2:], in [0, 1]. When the total variance is zero the index is zero.

    compatibility ¶

    compatibility(A, B)

    Equation 3: sup_z min(mu_A(z), mu_B(z)) for two trapezoidal fuzzy numbers.

    The supremum is attained either inside the intersection of the cores or at the crossing of the facing linear edges, for which a closed form exists.

    possibility_degree ¶

    possibility_degree(A, B)

    Possibility that A is at least B: sup_{x >= y} min(mu_A(x), mu_B(y)).

    fuzzy_ranking ¶

    fuzzy_ranking(numbers)

    Rank fuzzy numbers by the minimum possibility of exceeding every other number.

    Returns the order (indices from most to least important) and the dominance degree of every number, defined as min_j Poss(F_i >= F_j).
