# Roadmap

0.1.0 (this release): the method moved from the study repository, the estimator options, the existing plots, the tests of the properties.

0.2.0: the `Explanation` API in the style of shap (`values`, indexing by instance, `to_shap()`, `as_list()`, `as_html()`), the parity plots (bar, waterfall, beeswarm, heatmap, dependence, force, decision) and the SPARC specific plots (interval bars, linguistic profile, disagreement, concept graph, Pareto front with the fidelity optimal point, front navigator, selection membership, coverage).

0.3.0: documentation site with a plot gallery and tutorials, interactive plots with plotly, Zenodo DOI.
